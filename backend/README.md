An enterprise-grade, production-hardened Spring Boot microservice designed to serve as the core intelligence engine for the **ScholarOS ERP**. It powers curriculum management, lesson tracking, assessment authoring, automated evaluation, Google Gemini AI learning analysis, personalized homework generation, and class-level analytics.

---

## 🏛️ Architecture Overview

The ScholarOS Homework Intelligence Service strictly adheres to domain ownership principles and stateless JWT authentication:

- **ERP Integration**: The service maintains complete ownership of educational curricula, lessons, assessments, AI recommendations, homework assignments, and analytics records. It references ERP-owned domain entities (`studentId`, `teacherId`, `schoolId`, `sectionId`, `gradeId`, `academicYearId`) purely as UUID foreign identifiers without JPA mapping.
- **Stateless Authentication**: Accepts JWT bearer tokens generated by the ScholarOS ERP Auth server without maintaining server-side session state.
- **AI Intelligence Layer**: Integrates with Google Gemini API (`gemini-1.5-flash`) via structured JSON response parsing and feature-complete fallback engines.

## 🔐 Authentication & ERP Integration Contract

### 1. HTTP Authorization Header
All protected API requests must include the JWT token issued by ScholarOS ERP in the standard HTTP `Authorization` header:

```http
Authorization: Bearer <JWT_TOKEN>
```

### 2. Endpoint Protection Summary

| Endpoint Category | Paths | Authentication Required | Supported Roles |
| :--- | :--- | :--- | :--- |
| **System & Health** | `/api/v1/health`, `/actuator/health/*` | ❌ **Public** | Anyone |
| **API Documentation** | `/swagger-ui.html`, `/v3/api-docs/*` | ❌ **Public** | Anyone |
| **Curriculum Management** | `/api/v1/boards`, `/api/v1/curricula`, `/api/v1/chapters`, `/api/v1/topics` | ✅ **Required** | `ROLE_ADMIN`, `ROLE_TEACHER` |

| **Assessment Management** | `/api/v1/assessments/*` | ✅ **Required** | `ROLE_TEACHER`, `ROLE_ADMIN` |
| **Student Assessment Attempts**| `/api/v1/assessment-attempts/*` | ✅ **Required** | `ROLE_STUDENT`, `ROLE_TEACHER` |
| **AI Intelligence Engine** | `/api/v1/analysis/*`, `/api/v1/recommendations/*` | ✅ **Required** | `ROLE_TEACHER`, `ROLE_ADMIN` |

### 3. Expected JWT Payload Claims Specification

The ScholarOS ERP Auth Server and the Homework Microservice agree on the following standard JWT claims structure:

```json
{
  "sub": "b4e8590a-1122-3344-5566-778899aabbcc",
  "iss": "scholaros-erp-auth-service",
  "aud": "scholaros-homework-intelligence-service",
  "role": "ROLE_TEACHER",
  "schoolId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "sectionId": "f8e7d6c5-b4a3-2109-8765-43210fedcba9",
  "gradeId": "99887766-5544-3322-1100-aabbccddeeff",
  "academicYearId": "11223344-5566-7788-9900-aabbccddeeff",
  "iat": 1770144000,
  "exp": 1770230400
}
```

#### Claims Field Definitions:

| Claim Name | Type | Description |
| :--- | :--- | :--- |
| `sub` | `UUID (String)` | Unique User ID of the authenticated user in ERP |
| `role` | `String` | Role string (`ROLE_TEACHER`, `ROLE_STUDENT`, `ROLE_ADMIN`) |
| `schoolId` | `UUID (String)` | School UUID entity identifier from ERP |
| `sectionId` | `UUID (String)` | Section/Classroom UUID entity identifier from ERP |
| `gradeId` | `UUID (String)` | Grade/Class level UUID entity identifier from ERP |
| `academicYearId` | `UUID (String)` | Active Academic Year UUID identifier from ERP |
| `iat` | `Integer (Seconds)` | Issued-at Epoch Timestamp |
| `exp` | `Integer (Seconds)` | Expiration Epoch Timestamp |

## 🚀 Quick Start & Local Execution

### Prerequisites
- JDK 21+ installed
- PostgreSQL 16 running locally (or via Docker)

### Environment Variables
Copy `.env.example` to `.env` or set environment variables:

```bash
cp .env.example .env
```

| Variable | Description | Default Value |
| :--- | :--- | :--- |
| `SERVER_PORT` | HTTP Server Listening Port | `8080` |
| `SPRING_PROFILES_ACTIVE` | Active Spring Profile (`dev`, `prod`, `test`) | `dev` |
| `DATABASE_URL` | PostgreSQL JDBC Connection String | `jdbc:postgresql://localhost:5432/scholaros` |
| `DATABASE_USERNAME` | Database User | `postgres` |
| `DATABASE_PASSWORD` | Database Password | `root123` |
| `GEMINI_API_KEY` | Google Gemini API Key | `mock` |
| `JWT_SECRET` | Secret key for validating ERP JWT Tokens | Base64 Secret |

### Local Build & Execution

1. **Compile and Run Tests**:
   ```bash
   ./gradlew test
   ```

2. **Build Executable JAR**:
   ```bash
   ./gradlew bootJar
   ```

3. **Run Application**:
   ```bash
   java -jar build/libs/scholaros-0.0.1-SNAPSHOT.jar
   ```
